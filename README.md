# JMK Gen5W — 아이오닉 5 헤드유닛 패키지

국내형 **아이오닉 5 Gen5W AVNT 헤드유닛**(NEMESIS 루팅)에 설치하는 NEMESIS 패키지 3종입니다.

| 패키지 | 버전 | 하는 일 |
|---|---|---|
| **jmk-wifi** | 1.3.7 | USB Wi-Fi 동글을 **순정 Wi-Fi 모듈처럼** 동작시킵니다. 순정 핫스팟으로 무선 안드로이드 오토·카플레이, 동시에 폰 핫스팟 접속(인터넷·무선 adb) |
| **jmk-map-menu** | 2.2.2 | MAP 버튼 1.5초 → JMK 런처 메뉴: Wi-Fi, Active Ambient 설정, NEMESIS 매니저, 차박 모드(차박 +), 커스텀 워머창, USB(Phone / PC ADB) 전환, 재부팅 |
| **jmk-ambient-sound** | 2.5.5 | 음악·통화에 맞춰 실내 앰비언트 라이트를 움직입니다(인공지능 DJ / 무드 / 비트 / 단색 / 커스텀). 블루투스·USB·안드로이드 오토·**애플 카플레이** |

**설치 파일(USB 메모리용, 항상 최신판): [JMK-Gen5W-USB.zip 받기](https://github.com/JongMinKim-93/jmk-gen5w-ioniq5/releases/latest/download/JMK-Gen5W-USB.zip)** · 패키지별 zip은 [Releases](https://github.com/JongMinKim-93/jmk-gen5w-ioniq5/releases/latest)에 있습니다. 소스 코드는 공개하지 않습니다(드라이버 제외, 아래 라이선스 참고).

## 필요 조건

- 국내형 아이오닉 5, 펌웨어 **NEEV.KOR.0000.V039.001.260902**
- **NEMESIS** 루팅 (`nemesis install`이 동작하는 상태)
- jmk-wifi만: **RTL88x2BU 칩 USB 동글** (확인된 제품: ipTIME A3000MINI)

## jmk-wifi — 동글을 순정 Wi-Fi 모듈로

순정 Wi-Fi 칩이 없는 국내형 아이오닉 5에 USB 동글을 꽂아, 헤드유닛이 **"순정 Wi-Fi 모듈이 있다"고 인식**하게 합니다.

- 차 핫스팟은 순정 Wi-Fi 기능 그대로 동작합니다. 그래서 **순정 Wi-Fi를 쓰는 무선 안드로이드 오토 프로그램이라면 수정 없이** 쓸 수 있습니다. 동글 전용 패치나 추가 패키지가 필요 없습니다. 실차 확인: Evergreen 1.1.4, Leafia Plus v1.0.5 KOR.03-r8.2.
- 동시에 저장된 폰 핫스팟에 자동으로 접속해 헤드유닛에 인터넷과 무선 adb를 줍니다. 무선 AA 중에도 끊기지 않습니다.
- 설치할 때 시스템 파일 하나(`/system/lib/libhardware_legacy.so`)를 고칩니다. 원본은 백업해 두고, **제거하면 원래대로 되돌립니다.**
- 드라이버는 직접 빌드한 GPL 드라이버입니다(소스: `driver/`).

**순정 Wi-Fi 모듈이 있는 차:** 런처 메뉴 → Wi-Fi Driver의 폰 핫스팟 칸에서 접속 방법을 고릅니다.
- **동글:** USB 동글로 폰 핫스팟에 붙습니다. 차 핫스팟(무선 AA·카플레이)과 함께 됩니다.
- **순정 Wi-Fi:** 순정 모듈로 폰 핫스팟에 붙습니다. 순정 구조상 그동안 차 핫스팟이 꺼지고, ✕ 취소를 누르면 다시 켜집니다.
- **순정 동시 (시험):** 차 핫스팟을 켠 채 순정 모듈로 폰 핫스팟에도 붙어 봅니다. 순정에 없는 방식이라 시험 중이며, 결과가 개발자에게 자동으로 보내집니다.

- 순정 모듈은 순정 Wi-Fi(핫스팟)가 켜져 있을 때만 보입니다. **설치 전에 순정 Wi-Fi를 켜 두세요.** 한 번 감지되면 이후 업데이트에서도 접속 전용 모드가 유지됩니다.
- 설치 로그(USB 설치는 `JMK-INSTALL-LOG.txt`)에 감지 결과와 하드웨어 정보가 남습니다. 순정 모듈 차량이라면 이 로그를 카페나 깃허브 이슈로 보내 주시면 지원에 큰 도움이 됩니다.

처음 설정: 설치(아래 "설치·제거")와 재부팅 뒤, 런처 메뉴 → Wi-Fi Driver → 주변 찾기에서 폰 핫스팟을 고르고 비밀번호를 넣습니다.
다른 USB Wi-Fi 패키지(GRT47 usbwifi.hotspot 등)가 있으면 먼저 제거해야 합니다(있으면 설치가 거부됩니다).
JMK 런처 메뉴(jmk-map-menu)가 먼저 설치되어 있어야 설치됩니다(USB 묶음은 런처 메뉴부터 설치합니다). 런처 메뉴를 지우면 10분 뒤 차 핫스팟과 폰 핫스팟 접속도 꺼집니다(다시 설치하면 돌아옵니다).

## jmk-map-menu — JMK 런처 메뉴

MAP 버튼을 1.5초 누르면 화면 위에 런처 메뉴가 뜹니다. 다시 1.5초 누르거나, 바깥이나 ✕(왼쪽·오른쪽 위)를 누르면 닫힙니다. 메뉴가 떠 있는 동안에는 오른쪽 분할 화면을 잠시 접습니다.

- **Wi-Fi Driver** (jmk-wifi 설치 시): 차 핫스팟 상태·재시작·켜고 끄기, 폰 핫스팟 접속 상태, 저장된 네트워크, 주변 네트워크 찾기
- **Active Ambient** (jmk-ambient-sound 설치 시): 음악 재생 중 / 음악 멈춤 / 통화 중 / 공통 설정별로 조명 효과와 세부 설정
- **NEMESIS** 매니저 열기
- **차박 모드**: 5초 카운트다운 후 화면·조명을 끄고, 박수 두 번이면 음성 인식을 켭니다
  - **차박 +** (⚙ 설정 → 실험실): 차박 모드를 켤 때 앞좌석을 맨 앞으로 옮기고, 끌 때 운전석은 운전 자세 메모리로, 조수석은 맨 앞에서 3초 뒤로 돌려놓습니다. P단·정지 상태에서만 움직입니다. 실험실 모드는 서포터에게 우선 제공됩니다.
- 아래 줄
  - **버튼 매핑**: 메뉴를 여는 버튼(MAP · NAV · MEDIA · 콘솔 ☆ · 핸들 ☆)
  - **동의 화면 패스**: 시동 때 안전 안내 화면을 자동으로 닫습니다
  - **커스텀 워머창** (아래 참고)
  - **USB 포트**: Phone(USB 메모리·유선 AA·동글) / PC ADB(케이블 adb, 동글 꺼짐). 재부팅하면 Phone으로 돌아옵니다
  - **재부팅** (두 번 누르기)
- **⚙ 설정**: 업데이트 칸: 설치된 패키지 버전, 버전 옆 **업데이트 받기**, Wi-Fi Driver·Active Ambient **제거/다시 설치**, 후원 코드 · 실험실 칸: 차박 +

**커스텀 워머창** (처음에는 꺼져 있음): 켜면 WARMER 버튼을 눌렀을 때 순정 열선·통풍 팝업 대신 화면 아래에 JMK 워머창이 뜹니다. 안드로이드 오토·카플레이 화면은 그대로 유지됩니다.
- 핸들 열선, 운전석·조수석 열선/통풍, 뒷좌석 열선(있는 차만). 누를 때마다 강 → 중 → 약 → 끔 (뒷좌석은 강 → 약 → 끔)
- 바깥을 누르거나, WARMER를 다시 누르거나, 5초 동안 누르지 않으면 닫힙니다
- 켜 두는 동안 안드로이드 인텐트 방화벽 규칙(`/data/system/ifw/jmk-warmer.xml`)으로 순정 열선 팝업과, 공조 앱이 안드로이드 오토·카플레이에 보내는 "팝업 뜸" 알림을 막습니다. 끄거나 런처 메뉴를 제거하면 규칙도 지웁니다.
- 같은 알림을 블루링크 통화 팝업도 쓰기 때문에, 켜 두는 동안 카플레이 중 블루링크 통화 팝업은 카플레이 화면 위에 겹쳐 뜹니다(팝업 자체는 그대로 동작합니다).

## jmk-ambient-sound — 음악에 맞춘 앰비언트 라이트

재생 중인 음악을 분석해 실내 무드등 색과 밝기를 바꿉니다. 모드: 인공지능 DJ, 무드, 비트, 단색, 커스텀, 설정 없음. 통화 중 조명도 설정할 수 있습니다. 설정은 런처 메뉴 → Active Ambient에서 합니다(2.4.0부터 따로 실행하는 앱 화면은 없습니다).

JMK 런처 메뉴(jmk-map-menu)가 먼저 설치되어 있어야 설치되고 동작합니다.

**애플 카플레이 (2.3.0부터):** 카플레이 음악은 안드로이드 믹서를 거치지 않습니다. 그래서 설치할 때 카플레이 오디오 라이브러리(`/system/lib/libCarPlayAudio.so`)가 작은 중계 라이브러리(`libjmkalsa.so`)를 거치게, 연결 이름 하나만 바꿉니다. 소리는 그대로 나가고 복사본만 앰비언트로 갑니다. 재부팅 후부터 적용되고, 제거하면 카플레이 라이브러리를 원래 파일로 정확히 되돌립니다(4KB 중계 파일은 안전을 위해 남겨 둡니다). 모양이 다른 카플레이 라이브러리면 건드리지 않습니다. 2.4.5부터는 부팅할 때 앰비언트가 설치돼 있는데 중계가 빠져 있으면 다시 넣습니다(그다음 부팅부터 적용). 2.5.2부터는 라이브러리를 고치지 않고, 부팅할 때 카플레이 앱에 중계를 미리 불러오게 합니다(카플레이가 부팅 직후 한 번 다시 시작). 이 방식이 안 되는 차만 예전처럼 연결 이름을 바꿉니다.

## 차에서 업데이트 받기

헤드유닛이 폰 핫스팟에 연결돼 인터넷이 되면 **새 버전과 후원 여부를 스스로 확인**합니다(연결 30초 뒤, 그 뒤 6시간마다). 새 버전이 있으면 런처 메뉴의 **⚙ 설정** 버튼에 빨간 숫자가 붙고, 설정 화면의 그 패키지 옆 **⬇ v… 받기**를 두 번 누르면 설치됩니다. 자동으로 설치하지는 않습니다.

- **각 버전은 빌드 후 6개월 동안 쓸 수 있습니다.** 기간이 지나면 "업데이트가 필요합니다."가 뜨고 앰비언트 조명과 차박 모드가 멈춥니다. Wi-Fi와 설정 화면의 업데이트 받기는 계속 되므로, 폰 핫스팟에 연결해 설정 화면에서 최신 버전을 받으면 됩니다(USB 묶음으로 다시 설치해도 됩니다).
- 헤드유닛이 깃허브에 직접 접속하지 못해서 개발자 서버(gen5w.jmkim.dev)와 jsDelivr 등 CDN을 거쳐 받습니다.
- **보내는 정보:** 업데이트를 확인할 때 이 차의 후원 코드(8자, 이전 방식 코드 포함)·설치된 버전·Wi-Fi 종류(순정 모듈/동글)·헤드유닛 펌웨어 버전과 차종 코드(예: `NEEV.KOR.0000.V039.001.260902`, `NE1AE.S5BM`; 같은 차종이면 모두 같은 값이라 차를 알아볼 수 없습니다)를 개발자 서버에 보냅니다. 동글을 쓰는 차는 그 동글의 USB 모델명(제조사·제품명)도 함께 보냅니다(어떤 동글이 쓰이는지 드라이버 지원 파악용). 순정 Wi-Fi 모듈 차는 모델명을 보내지 않습니다. 오류가 나거나 시험 기능을 쓰면 그 내용(오류 메시지, 펌웨어·버전)도 보냅니다. 2026-11-14 업데이트(런처 메뉴 2.2.1 · Active Ambient 2.5.5 · Wi-Fi Driver 1.3.7)부터는 기능이 조용히 실패한 경우도 보냅니다: 폰 핫스팟에 붙지 못한 이유(핫스팟이 안 보임·비밀번호 단계에서 끊김·주소를 못 받음 같은 분류와 저장된 핫스팟의 대역·채널, 업데이트를 확인할 때도 마지막 실패 분류를 함께 보냄), 차 핫스팟이 거듭 다시 켜진 이유, 동글·드라이버를 찾지 못함, 설치 스크립트 실패, 런처 메뉴·커스텀 워머창·차박 모드·동의 화면 패스·USB 모드·실험실이 보낸 명령의 실패(명령 이름과 결과 값), 메뉴·워머창이 뜨지 않음, 업데이트 파일 검증 실패, Active Ambient의 조명 명령 실패·소리 캡처 끊김·조명 작업 종료·설정 파일 거부(파일 내용은 보내지 않음). 노래 제목, 통화 상대, 바로가기에 넣은 앱 이름은 보내지 않습니다. Wi-Fi 이름·비밀번호·위치는 보내지 않고, MAC·IP 주소는 지우고 보냅니다. 아이오닉 5 KR(V039 260902)이 아닌 헤드유닛(다른 차종·다른 펌웨어)은 처음 한 번, 헤드유닛 소프트웨어의 명령 이름과 번호 목록도 보냅니다. 같은 펌웨어면 모든 차가 같은 목록이라 차를 알아볼 수 없습니다. 다른 차종에 잠긴 채로 설치되면 그 헤드유닛의 기기명·펌웨어 지문·차종 코드(Wi-Fi Driver는 커널과 네트워크 장치 목록)를 한 번 보냅니다. 오류 보고는 런처 메뉴 → ⚙ 설정의 "오류 보고"로 끌 수 있습니다.
- 업데이트 목록(`update/manifest.signed`)은 개발자 키로 서명되어 있고, 파일마다 크기·SHA-256을 확인합니다. 하나라도 맞지 않으면 설치하지 않습니다.

## 설치·제거

**USB 메모리로 한 번에 설치 (권장)**
1. [JMK-Gen5W-USB.zip](https://github.com/JongMinKim-93/jmk-gen5w-ioniq5/releases/latest/download/JMK-Gen5W-USB.zip)을 받아 USB 메모리 맨 위에 압축을 풉니다(`NEMESIS.sh`와 `packages` 폴더가 맨 위).
2. 시동을 켜고 USB를 꽂은 뒤 NEMESIS 창에서 `NEMESIS.sh`를 실행합니다.
3. 런처 메뉴 → 앰비언트 → Wi-Fi Driver 순서로 설치(이미 있으면 업데이트)되고 헤드유닛이 다시 시작합니다. 결과는 USB의 `JMK-INSTALL-LOG.txt`.
4. USB를 빼고 동글을 꽂습니다.

- 다른 Wi-Fi 앱(예: Korea Projection)이 있는 차는 Wi-Fi Driver를 건너뛰고 런처 메뉴와 앰비언트만 설치합니다(이유는 `JMK-INSTALL-LOG.txt`에 남습니다). Wi-Fi Driver 1.3.4부터는 설치 파일을 직접 넣어도 설치되지 않습니다.
- HMG Leafia Plus와 함께 쓸 때: Active Ambient 2.5.2부터는 카플레이 라이브러리를 고치지 않습니다. 그 전 버전이 있으면 먼저 2.5.2로 업데이트하고 재부팅한 뒤 Leafia를 설치하세요.
- 아이오닉 5가 아닌 차종에도 모두 설치됩니다(USB 설치 포함). 차에 명령을 보내는 기능은 그 차종이 확인될 때까지 잠깁니다. 커스텀 워머창·차박 모드·동의 화면 패스는 꺼지고, Active Ambient는 조명 명령을 보내지 않으며 설정은 읽기 전용입니다. 헤드유닛 커널이 다른 차는 Wi-Fi Driver가 설치돼도 드라이버를 올리지 않고 ⚙ 설정에 "이 차종 미지원"이 뜹니다. NEMESIS·USB 모드·재부팅·버튼 매핑·바로가기는 그대로 쓸 수 있습니다. 차종별로 확인되면 업데이트 확인 때 풀립니다.
- 인터넷에 연결되지 않는 차는 자동 업데이트가 되지 않으니, 가끔 USB 설치 파일로 업데이트해 주세요.

- adb로 하나씩: 패키지 zip을 헤드유닛에 넣고 `nemesis install <zip>`, 업데이트는 `nemesis install --update <zip>`
- 제거: 런처 메뉴 → ⚙ 설정에서 Wi-Fi Driver·Active Ambient(Wi-Fi Driver는 재부팅하면 끝남), 또는 `nemesis uninstall jmk-wifi` / `jmk-map-menu` / `jmk-ambient-sound`
- 어떤 패키지든 문제가 생기면 제거하고 재부팅하면 원래 상태로 돌아갑니다.
